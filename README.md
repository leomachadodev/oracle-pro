## 🎯 What is Oracle?

Oracle é uma plataforma de automação de marketing alimentada por 22 agentes de IA especializados. Cada agente é treinado para uma tarefa específica:

- 📧 Email automation
- 📱 Social media management
- 📊 Analytics & insights
- 💼 Lead management
- 🎯 Campaign optimization
- 🤖 Chatbots & support
- ➕ 16 more specialized agents

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/leomachadodev/oracle-pro.git
cd oracle-pro
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Setup
```bash
cp .env.example .env.local
```

Configure:
```env
NEXT_PUBLIC_APP_URL=http://localhost:3000
DATABASE_URL=postgresql://...
CLAUDE_API_KEY=sk-...
OPENAI_API_KEY=sk-...
```

### 4. Initialize Database
```bash
npm run db:migrate
npm run db:seed
```

### 5. Run Development Server
```bash
npm run dev
```

Open: **http://localhost:3000**
